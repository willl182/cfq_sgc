# Technical Finding / Milestone

**Context**: Implementación de módulos del plan_v1 en la app vanilla JS

## The Discovery

Se implementaron 6 módulos nuevos que cubren las Fases 1-5 del plan_v1.md:

1. **seed.js** — Catálogo unificado con IDs secuenciales (MP####/PT####/MZR####), validación CSV, auditoría de cambios, admin local, búsqueda, archivado soft
2. **formulas.js** — Motor de cálculo puro sin dependencias DOM: `calcularComposicion()`, `calcularTotalKg()`, `congelarComponentes()`
3. **tolerancias-v2.js** — Motor de tolerancias con estados CUMPLE/CUMPLE_S/NO_CUMPLE/SIN_OBJETIVO (compatible con el legacy tolerancias.js pero con nuevas reglas)
4. **catalogo-unificado.js** — Vista unificada que reemplaza catalogo.js + inventario-editor.js. Carga automática del CSV, edición inline, admin toggle, historial de cambios
5. **product-lists.js** — Listas vivas y snapshots versionados. Cada guardado crea lista viva + snapshot. Snapshots inmutables con versión (v1, v2...). Clonación de snapshots a nuevas listas
6. **historico.js** — Vista de snapshots con filtros, detalle congelado, clonación, archivado

Regla clave MZR: filas con COD empezando por R, R1, R2... (regex `/^(R\d{0,2}|R)$/`)
