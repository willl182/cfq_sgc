# Technical Finding / Milestone

**Context**: Simplificación del procedimiento de retiro de producto

## The Discovery

El documento de retiro estaba más complejo de lo necesario para su uso cotidiano. Una versión más útil para postventa funciona mejor si:

- Comercial/Ventas lidera la localización y el seguimiento de clientes.
- Servicio al Cliente registra la evidencia de contacto.
- Calidad valida el lote y el alcance técnico.
- Dirección Técnica interviene solo para activar y cerrar.
