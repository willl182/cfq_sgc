# Technical Finding: Formulador CFQ v2 - Convex + React + TypeScript

**Context**: Migracion completa del Formulador CFQ de Google Apps Script + JS vanilla a Convex + React + TypeScript

## The Discovery

1. **Convex schema con tablas anidadas**: Los campos de nutrientes (20 campos) se definieron inline usando spread de `v.number()` en el schema. Para TypeScript, Convex genera tipos estrictos que no aceptan `Record<string, number>` directamente - hay que castear con `as any` en ciertos sitios o listar los campos explicitamente.

2. **Clasificacion MZR del CSV**: Los items con `COD = "R"` o `COD = "R1"`, `"R2"` etc. se clasifican como MZR (mezcla para reemplazo), no como PT. Esto se maneja en la mutacion `seedFromCsv`.

3. **IDs secuenciales**: Se asignan en orden del CSV agrupados por clase: MP0001-MP0008, PT0001-PT0xxx, MZR0001-MZR0xxx. El padding es a 4 digitos.

4. **Calculo compartido**: El modulo `tolerancias.ts` se usa tanto client-side (preview en el formulador) como server-side (en las mutaciones de Convex). Convex importa directamente desde `../src/lib/tolerancias.ts`.

5. **Snapshot en cada guardado**: Cada `save` en productLists crea simultaneamente una lista viva (o actualiza existente) Y un snapshot versionado. Los snapshots son inmutables y no se recalculan nunca.

## Key Files Affected

- `web/convex/schema.ts` - Schema canonico de 4 tablas
- `web/convex/catalogItems.ts` - Queries del catalogo
- `web/convex/catalogMutations.ts` - Seed CSV, update, archive, clear
- `web/convex/productLists.ts` - Save lista + snapshot con calculo server-side
- `web/convex/productListSnapshots.ts` - Queries, archive, clone
- `web/src/lib/constants.ts` - Constantes y tipos compartidos
- `web/src/lib/tolerancias.ts` - Motor de calculo y tolerancias (puro, sin UI)
- `web/src/lib/index.ts` - Re-exports y utilidades UI
- `web/src/views/CatalogView.tsx` - Vista catalogo completa
- `web/src/views/FormuladorView.tsx` - Formulador con componentes dinamicos
- `web/src/views/HistoricoView.tsx` - Historico de snapshots
- `web/src/components/Layout.tsx` - Layout con sidebar y admin toggle
- `web/src/styles/index.css` - Estilos dark theme completos
