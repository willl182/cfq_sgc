# Technical Finding / Milestone

**Context**: Implementación del plan integrado `grillme/plan_v1.md` en el formulador CFQ.

## The Discovery

Se implementó el modelo canónico de Convex con 4 tablas unificadas (`catalogItems`, `catalogChangeHistory`, `productLists`, `productListSnapshots`), motor de cálculo puro compartido client/server, tolerancia ICA en 3 grupos, y UI React con permisos locales.

## Key Files Affected

- `web/convex/schema.ts` — Schema canónico de 4 tablas con 20 nutrientes.
- `web/convex/seed.ts` — Carga inicial desde CSV con validación y clasificación MZR.
- `web/convex/catalog.ts` — CRUD de catálogo + historial de cambios.
- `web/convex/lists.ts` — Listas vivas, snapshots versionados y clonado.
- `web/lib/calculation.ts` — Motor de cálculo de composición.
- `web/lib/tolerancia.ts` — Motor de tolerancia ICA (3 grupos).
- `web/lib/csvParser.ts` — Parser de CSV con clasificación MZR.
- `web/src/pages/CatalogPage.tsx` — UI de catálogo editable.
- `web/src/pages/FormulatePage.tsx` — UI de formulación con preview.
- `web/src/pages/SnapshotsPage.tsx` — UI de histórico de snapshots.
- `web/src/pages/AdminPage.tsx` — Carga de CSV y auth local.
- `web/src/pages/ImportPage.tsx` — Importación futura (preview).
- `web/src/hooks/useLocalAuth.ts` — Auth local por localStorage.
- `web/vite.config.ts` — Configuración Vite con React.
- `web/package.json` — Dependencias: React, Convex, React Router, Tailwind.
- `web/tsconfig.json` — Configuración TypeScript con `strict: false` (revisar).
