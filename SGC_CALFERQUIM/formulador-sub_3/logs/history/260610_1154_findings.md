# Technical Finding / Milestone: Auth Real Implementado en Convex

**Context**: Implementación de sistema de autenticación real con roles persistidos en Convex para el Formulador CFQ

## La Implementación

Se implementó un sistema completo de autenticación y autorización reemplazando el sistema anterior basado en `localStorage` (`useLocalAuth`) por uno persistente en Convex (`useAuth`).

### Schema Actualizado

- Tabla `users` agregada al schema de Convex con campos:
  - `name`, `email`, `passwordHash`, `role` (admin/user), `isActive`, `createdAt`, `lastLoginAt`
  - Índices: `by_email`, `by_role`, `by_active`

### Backend (Convex)

- **Nuevo archivo**: `convex/auth.ts`
- Mutaciones implementadas:
  - `register`: Crear usuario con validación de email único
  - `login`: Autenticación con token simple y actualización de `lastLoginAt`
  - `getCurrentUser`: Query para obtener usuario desde token
  - `listUsers`: Listar usuarios (activos/inactivos)
  - `updateUser`: Actualizar rol/estado de usuario
  - `changePassword`: Cambiar contraseña con verificación de contraseña actual
  - `getUserFromToken`: Helper para validar token en otras mutaciones

### Frontend (React)

- **Nuevo hook**: `src/hooks/useAuth.ts`
  - Reemplaza completamente `useLocalAuth`
  - Usa token persistente en `localStorage` (`cfq_auth_token`)
  - Expone: `user`, `isAdmin`, `token`, `login`, `register`, `logout`
  - `login` y `register` son funciones asíncronas que llaman a Convex

### Protección de Mutaciones

- `createCatalogItem`: Solo admin puede crear PT/MZR
- `updateCatalogItem`: Solo admin puede editar PT/MZR (usuarios normales pueden editar MP)
- `archiveCatalogItem`: Solo admin puede archivar PT/MZR
- Token se pasa como argumento `token` opcional en las mutaciones

### UI Actualizada

- **AdminPage**: 
  - Login con email/contraseña
  - Registro de nuevos usuarios (admin puede crear admins)
  - Gestión de usuarios: tabla con activar/desactivar, cambiar rol
- **Navbar**: Muestra nombre del usuario y rol (Admin)
- **CatalogPage**: Verifica `isAdmin` para mostrar botón "Crear PT/MZR"
- **SnapshotsPage**: Verifica `isAdmin` para mostrar botón "Archivar"

### Decisión Técnica: Hash Simple

Se usó una función hash simple (no criptográfica) para contraseñas con la nota explícita de que en producción debe reemplazarse por bcrypt o similar. Esto es aceptable para el entorno local actual.

## Key Files Affected

- `convex/schema.ts` — Tabla `users` agregada
- `convex/auth.ts` — Nuevo archivo con mutaciones de auth
- `convex/catalog.ts` — Validación de admin en mutaciones protegidas
- `src/hooks/useAuth.ts` — Nuevo hook de autenticación
- `src/hooks/useLocalAuth.ts` — Obsoleto (ya no se usa)
- `src/components/Navbar.tsx` — Actualizado para usar `useAuth`
- `src/pages/AdminPage.tsx` — Login, registro, gestión de usuarios
- `src/pages/CatalogPage.tsx` — Validación de permisos
- `src/pages/FormulatePage.tsx` — Usa `useAuth`
- `src/pages/SnapshotsPage.tsx` — Usa `useAuth`
