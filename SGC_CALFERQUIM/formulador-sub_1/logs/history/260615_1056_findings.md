# Technical Finding / Milestone

**Context**: UI del formular (`Formular`) en `formulador-sub_1/web`

## The Discovery

El bloque "Nuevo producto objetivo" usaba un grid de una sola fila con muchas columnas (`minmax(190px, 1fr) 110px minmax(190px, 1fr) 90px auto`). Eso comprimia el boton "Crear PT" hasta cortar su texto y dejaba los inputs sin aire suficiente.

La solucion fue dividir el bloque en dos filas semanticas:
1. Header informativo (titulo + descripcion) a todo el ancho.
2. Campos de entrada (`COD opcional`, `Nombre`, `Tipo`) y el boton `Crear PT` en una segunda fila con columnas fijas pero flexibles.

Ademas se ajusto:
- `.section-title` y `.form-actions` para permitir wrap y alineacion consistente entre el titulo y los botones.
- `.form-grid` aumento su minimo de `360px` a `460px` para evitar compresion del panel izquierdo.
- En la media query movil los campos del target-create se apilan en una sola columna.

## Key Files Affected

- `web/src/main.tsx`: reestructuracion JSX del bloque `.target-create`.
- `web/src/style.css`: ajustes de layout para `.target-create`, `.target-create-fields`, `.form-actions`, `.section-title` y `.form-grid`.
