# Technical Finding / Milestone

**Context**: Creacion directa de listas y productos objetivo desde el formulador.

## The Discovery

El sistema ya podia crear items manuales desde Catalogo, pero para el flujo de verificacion era demasiado indirecto. Se agrego una accion directa en Formulador:

- `Nueva lista`: reinicia lista activa, objetivo y componentes sin tocar catalogo ni snapshots.
- `Nuevo producto objetivo`: crea un `PT` manual, lo selecciona como objetivo, lo deja listo para verificar cumplimiento y abre el editor de nutrientes para declarar composicion objetivo.

El flujo conserva la regla de permisos: crear `PT` manual requiere `Admin local`, usando la mutacion Convex existente `catalog.createManual`.

## Key Files Affected

- `web/src/main.tsx`: estados de producto objetivo nuevo, `startNewList`, `createTargetProduct`, botones y bloque de creacion desde Formulador.
- `web/src/style.css`: estilos compactos para acciones del formulador y bloque `Nuevo producto objetivo`.
