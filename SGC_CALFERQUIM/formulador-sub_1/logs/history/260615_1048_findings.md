# Technical Finding / Milestone

**Context**: Despliegue completo Convex + Vercel del formulador.

## The Discovery

La app completa requiere dos capas en produccion:

- Convex para schema, funciones, queries/mutations y persistencia.
- Vercel para servir el frontend React/Vite.

`npx convex deploy` identifico que el entorno de desarrollo local apuntaba a `valiant-stingray-191`, pero el deployment de produccion real del proyecto es `sensible-goose-293`. El frontend publicado debe usar `VITE_CONVEX_URL=https://sensible-goose-293.convex.cloud`.

## Key Files Affected

- No se modifico codigo fuente en este despliegue.
- Se actualizo configuracion remota de Vercel: `VITE_CONVEX_URL` en production.
- Feature previamente presente:
  - `web/src/domain/exportLists.ts`
  - `web/src/main.tsx`
  - `web/src/domain/domain.test.ts`

## Verification

- `npm test` en `web/`: 12 pruebas pasadas.
- `npm run build` en `web/`: exitoso.
- `npx convex deploy` en `web/`: exitoso; schema validation complete e indices agregados.
- `vercel --prod --yes` en `web/`: exitoso.
- `curl https://formulador-sub.vercel.app/`: HTTP 200.
- Bundle publicado contiene `https://sensible-goose-293.convex.cloud` y funciones de exportacion (`cfq-listas-vivas`, CSV/JSON).
