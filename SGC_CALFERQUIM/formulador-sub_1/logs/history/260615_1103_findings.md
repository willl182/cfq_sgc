# Technical Finding / Milestone

**Context**: Deploy a produccion de ajustes de UI en `formulador-sub_1/web`

## The Discovery

Se desplegaron los cambios de UI de la pantalla `Formular` a produccion usando el flujo de build prebuilt desde `web/`:

```bash
vercel build --prod
vercel deploy --prebuilt --prod --yes
```

El deploy fue exitoso y el dominio de produccion `https://formulador-sub.vercel.app/` quedo apuntando a la nueva version. La verificacion HTTP devolvio 200 y el HTML contiene el titulo `Formulador SGC CALFERQUIM`.

Deployment URL directo: `https://vercel.com/will-salas-projects/formulador-sub/CbxzwUJZEmh3TrDfSQx8VqdbLo1L`
Production alias: `https://formulador-sub.vercel.app/`

## Key Files Affected

- `web/src/main.tsx`: reestructuracion JSX del bloque `.target-create`.
- `web/src/style.css`: ajustes de layout para `.target-create`, `.target-create-fields`, `.form-actions`, `.section-title` y `.form-grid`.
