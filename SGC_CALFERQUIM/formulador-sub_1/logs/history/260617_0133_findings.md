# Technical Finding / Milestone

**Context**: Edición de clase (MP/PT/MZR) en el catálogo del Formulador SGC.

## The Discovery

El catálogo no permitía modificar la clase de un item después de su creación. Se implementó una mutación `updateClass` en Convex y un select en el detail drawer para cambiar entre MP, PT y MZR.

Puntos clave de la implementación:

- La mutación `updateClass` en `web/convex/catalog.ts` solo permite cambios por usuarios `admin`, valida que la clase sea distinta y registra el cambio en `catalogChangeHistory` con origen `catalog.class_edit`.
- En `web/src/main.tsx` se agregó el hook `useMutation(api.catalog.updateClass)`, la función `updateClass` y un select dentro del drawer de detalle, junto al selector de estado físico.
- Se ajustó el tipo `CatalogChange` y la función `mapConvexChange` para soportar valores `number | string`, permitiendo mostrar correctamente los cambios de clase en el historial.
- Se agregó la etiqueta "Clase" en `formatCompositionField` para renderizar el campo de forma legible.
- Si el item aparece en listas guardadas, se muestra una confirmación previa para evitar cambios accidentales que afecten formulaciones o productos objetivo.

## Key Files Affected

- `web/convex/catalog.ts`
- `web/src/main.tsx`
- `web/src/style.css`
