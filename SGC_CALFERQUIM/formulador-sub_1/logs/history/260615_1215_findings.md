# Technical Finding / Milestone

**Context**: Consolidado operacional de insumos en `formulador-sub_1`.

## The Discovery

La necesidad del usuario se resuelve como una agregación por insumo sobre listas vivas ya guardadas: cada lista seleccionada aporta `component.quantityKg * multiplier`, y los aportes se suman por `CatalogItem.internalId`.

Esto permite calcular el total requerido de MP/insumos para preparar varias listas o varios lotes sin alterar formulaciones, snapshots ni composición declarada.

## Key Files Affected

- `web/src/domain/listTotals.ts`: nueva función pura `summarizeRequiredInputs()`.
- `web/src/domain/domain.test.ts`: prueba de suma por insumo con varias listas y multiplicadores.
- `web/src/main.tsx`: UI nueva en la vista `Escalar` para seleccionar varias listas y mostrar totales.
- `web/src/style.css`: estilos del bloque de selección múltiple y tabla consolidada.
