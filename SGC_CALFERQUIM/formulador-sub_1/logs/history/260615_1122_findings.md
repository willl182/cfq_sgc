# Technical Finding / Milestone

**Context**: Formulador React - modulo de preparacion por multiplicador

## The Discovery

Se implemento una vista operacional `Preparar` para escalar una lista viva guardada mediante un multiplicador. El calculo es intencionalmente simple: cada cantidad base se multiplica por el factor ingresado y se muestra el total a preparar.

Este modulo no modifica la lista original, no guarda snapshot y no recalcula la composicion nutricional. Sirve para convertir listas base como 1 kg, 1000 kg o 1 tonelada a la cantidad real de preparacion.

## Key Files Affected

- `web/src/main.tsx`: nueva vista `scale`, seleccion de lista, multiplicador y tabla de cantidades escaladas.
- `web/src/style.css`: estilos responsivos para resumen y tabla del modulo.

## Verification

- `npm run build` paso correctamente con TypeScript y Vite.
