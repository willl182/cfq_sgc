# Technical Finding / Milestone

**Context**: Continuacion de `grillme/plan_v1.md` para cerrar importacion futura y visibilidad de auditoria.

## The Discovery

La importacion futura puede implementarse de forma segura como preview puro del lado cliente mientras Convex no esta conectado. El parser `parseListImportCsv` valida el formato esperado, cruza IDs contra el catalogo activo y agrupa filas por `productoObjetivoId + listaAlias` sin tocar `productLists` ni snapshots.

Tambien se agrego una tabla global de cambios recientes del catalogo usando el historial local existente, para que la auditoria no dependa solo del item seleccionado en el drawer.

## Key Files Affected

- `web/src/domain/importLists.ts`: parser y validador puro para CSV de listas futuras.
- `web/src/domain/domain.test.ts`: tests de agrupacion valida y errores de importacion.
- `web/src/main.tsx`: nueva vista `Importar`, navegacion lateral, preview de grupos/errores y auditoria global.
- `web/src/style.css`: estilos para importacion, resumen, grupos, errores y tabla de auditoria.
