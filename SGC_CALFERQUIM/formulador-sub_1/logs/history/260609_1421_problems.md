# Problem Record (Troubleshooting)

**Severity**: Low

## The Problem

El primer `pnpm build` fallo porque el starter mantenia configuracion TypeScript sin soporte JSX y `index.html` apuntaba a `/src/main.ts`, archivo eliminado al crear `main.tsx`.

Errores principales:

- `Cannot use JSX unless the '--jsx' flag is provided.`
- `Failed to resolve /src/main.ts from index.html`

## User-Requested Corrections

- Implementar `grillme/plan_v1.md`.

## The Solution / Workaround

- Se agrego `"jsx": "react-jsx"` a `web/tsconfig.json`.
- Se actualizo `web/index.html` para usar idioma `es`, titulo del formulador y entrypoint `/src/main.tsx`.
- Se agrego `web/vite.config.ts` con plugin React.

## Learnings to Preserve

- En este scaffold, cualquier migracion a React debe actualizar simultaneamente `tsconfig.json`, `vite.config.ts` e `index.html`.
- Convex queda fuera del typecheck de `web/src` hasta generar `web/convex/_generated`; no asumir que `pnpm build` valida funciones Convex.
