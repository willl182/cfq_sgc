# Technical Finding / Milestone

**Context**: Fase de catalogo editable del formulador.

## The Discovery

El CSV debe tratar `COD` tipo `R`, `R1`, `R2`, etc. como mezcla recursiva (`MZR`) con precedencia sobre la columna `CLASE`. Despues de corregir la precedencia, el seed esperado queda en `MP=8`, `PT=268`, `MZR=20`.

Tambien se implemento creacion manual de items `MP`, `PT` y `MZR` desde la UI. Los nuevos registros reciben `internalId` secuencial por clase y conservan `COD`/codigo original como trazabilidad.

## Key Files Affected

- `web/src/domain/catalog.ts`: precedencia `COD R* => MZR`.
- `web/src/domain/domain.test.ts`: pruebas para duplicados de `COD` y precedencia `MZR`.
- `web/src/main.tsx`: boton limpiar local, panel de detalle, editor de 20 nutrientes, auditoria local y creacion manual.
- `web/src/style.css`: layout de catalogo, panel lateral y formulario de creacion.
