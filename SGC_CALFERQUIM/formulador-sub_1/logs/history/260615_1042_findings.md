# Technical Finding / Milestone

**Context**: Deploy a produccion del feature de exportacion de listas.

## The Discovery

El proyecto Vercel `formulador-sub` estaba enlazado en la raiz de `formulador-sub_1`. Un deploy directo desde la raiz publico la app legacy (`index.html` + `app.js`), no la app React ubicada en `web/`.

La correccion fue enlazar `web/` al mismo proyecto Vercel, ejecutar build local de Vercel desde `web/` y subir el artefacto prebuilt. Esto uso la configuracion local de Convex disponible en `web/.env.local`, ya que el proyecto Vercel no tenia variables de entorno remotas configuradas.

## Key Files Affected

- No quedaron cambios de archivos por el deploy.
- Feature previamente implementado en:
  - `web/src/domain/exportLists.ts`
  - `web/src/main.tsx`
  - `web/src/domain/domain.test.ts`

## Verification

- `npm test` en `web/`: 12 pruebas pasadas.
- `npm run build` en `web/`: exitoso.
- `vercel build --prod` en `web/`: exitoso.
- `vercel deploy --prebuilt --prod --yes` en `web/`: exitoso.
- `curl https://formulador-sub.vercel.app/`: HTTP 200 y HTML de React/Vite con titulo `Formulador SGC CALFERQUIM`.
