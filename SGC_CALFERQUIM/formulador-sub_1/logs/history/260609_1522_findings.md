# Technical Finding / Milestone

**Context**: Avance de la fase Convex server-side del formulador.

## The Discovery

La mutacion Convex `saveWithSnapshot` fue ajustada para que el servidor sea la autoridad del snapshot: recibe solo lista viva, objetivo y componentes; resuelve los `catalogItems` activos, normaliza cantidades a 2 decimales, calcula composicion final, evalua tolerancias, genera alertas de total distinto de 1000 kg y congela objetivo/componentes en `productListSnapshots`.

Esto evita que el cliente pueda enviar composicion calculada, evaluacion o componentes congelados manipulados como fuente de verdad.

Tambien se agregaron operaciones de catalogo server-side para auditoria visible futura: `recentChanges`, `createManual` y `archive`.

## Key Files Affected

- `web/convex/productLists.ts`: calculo y snapshot server-side autoritativo.
- `web/convex/catalog.ts`: queries/mutations de historial reciente, creacion manual y archivado con auditoria.
