# Technical Finding / Milestone

**Context**: Optimizacion de captura en `Catalogo unificado`

## The Discovery

La lentitud percibida al ingresar composiciones venia de persistir cada pulsacion directamente desde `updateComposition()`. Cada tecla programaba guardado, actualizaba historial de auditoria y forzaba renders de catalogo, lo que hacia pesada una tarea que debe ser de captura rapida.

## Implementacion

- Se separo el valor visible del input del valor persistido mediante `compositionDrafts`.
- Se agrego debounce por campo con `compositionSaveTimers`.
- Se agregaron referencias para consolidar valores pendientes por item antes de persistir la composicion completa.
- Se mantuvo compatibilidad con Convex y con el modo localStorage.
