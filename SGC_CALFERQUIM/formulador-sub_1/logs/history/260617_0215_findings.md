# Technical Finding / Milestone

**Context**: Reordenamiento manual de insumos en el formulador de listas.

## The Discovery

Se implementó drag-and-drop nativo de HTML5 para reordenar los componentes de una lista de formulación. El patrón utilizado evita conflictos con los inputs y comboboxes internos de cada fila:

1. Solo el `drag-handle` (icono `GripVertical`) es `draggable`, no la fila completa.
2. Al iniciar el arrastre se clona la fila completa y se usa como imagen personalizada (`setDragImage`) para que el usuario vea el componente que está moviendo.
3. El índice origen se transporta mediante `dataTransfer.setData('text/plain', String(index))`.
4. En `onDrop` se invoca `moveComponent(from, to)` que muta inmutablemente el arreglo `components`.
5. El estado `dragOverIndex` activa un borde superior verde en la fila objetivo para dar feedback inmediato.

## Key Files Affected

- `web/src/main.tsx`: Estados, función `moveComponent` y render de las filas.
- `web/src/style.css`: Estilos del handle, estados `dragging`/`drag-over` y ajustes responsive.
