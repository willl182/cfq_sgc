# Technical Finding / Milestone

**Context**: Feature de visibilidad de composición en el catálogo del formulador CALFERQUIM.

## The Discovery

Se implementó una forma rápida de auditar el catálogo identificando items con/sin datos de composición nutricional. Esto es útil para la transición regulatoria R150 -> pv0 porque permite detectar productos o materias primas que aún no tienen especificaciones técnicas completas.

## Key Files Affected

- `web/src/domain/catalog.ts`: agrega `hasCompositionInfo(item)`.
- `web/src/main.tsx`: filtro `compositionFilter`, badge por fila y estadísticas.
- `web/src/style.css`: estilos `.composition-badge`, `.with-composition`, `.without-composition`.
- `web/src/domain/catalog.test.ts`: tests unitarios para `hasCompositionInfo`.
