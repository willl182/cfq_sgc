## Estructura Estándar por Producto

Cada producto registrado tiene la siguiente estructura:

```
[NOMBRE_PRODUCTO]/
├── 01_Registro_Venta/          # Registro ICA, certificados de venta
├── 02_Ficha_Tecnica/           # Fichas técnicas de producción
├── 03_Etiqueta_Aprobada/       # Etiquetas aprobadas por ICA
├── 04_Hoja_Seguridad/          # Hojas de seguridad (SDS)
│   └── HS_[PRODUCTO]_Item[XXX].[ext]
└── 05_Soportes_Ensayo/         # Certificados de análisis laboratorio
```

## Convenciones de Nomenclatura

### Hojas de Seguridad

```
HS_[NOMBRE_PRODUCTO]_Item[XXX].[ext]

Ejemplos:
- HS_SILIMAGRAN_Item35.docx
- HS_NUCLEO_4.docx (HS propia)
- HS_ZUELO_CA.docx (HS propia)
```

### Fichas Técnicas (por implementar)

```
FT_[NOMBRE_PRODUCTO]_V[VERSION].[ext]

Ejemplos:
- FT_SILIMAGRAN_V1.docx
- FT_NUCLEO_4_V2.pdf
```
