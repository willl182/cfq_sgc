# Sección 5: Cumplimiento Técnico del Producto

## Requisitos Críticos ya Integrados en Control

| Requisito | Criterio ICA |
|:---|:---|
| NPK (1 nutriente mayor) | >= 10% |
| NPK compuesto sólido edáfico | >= 18% (sumatoria) |
| NPK compuesto fertirriego | >= 15% (sumatoria) |
| Metales pesados | As 41, Cd 39, Pb 20 mg/kg |

## Soporte Existente en el SGC

- Herramientas de formulación/verificación en laboratorio (`.xlsm`).
- Resultados externos y certificados para respaldo analítico.
- Procedimientos de muestreo y liberación de lotes ya documentados.

# Sección 6: Brechas para Cumplimiento Total

## Top 5 Acciones de Cierre (Prioridad Alta)

::: incremental

- Formalizar contrato de Asesor Técnico con acompañamiento permanente.
- Emitir procedimiento de Balance de Masas.
- Emitir procedimiento de Contramuestras.
- Emitir procedimiento de Recall / Retiro de Producto.
- Emitir procedimiento de Disposición de Barreduras (sin reutilización).
