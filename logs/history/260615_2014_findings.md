# Technical Finding / Milestone

**Context**: Busqueda y ordenamiento en Snapshots congelados.

## The Discovery

La vista de snapshots renderizaba tarjetas directamente desde `snapshots.map`, sin filtro ni orden configurable. Se agrego `SnapshotSearchCombobox` con el mismo sistema visual de desplegable propio usado en catalogo/formulador, y se derivo `visibleSnapshots` para filtrar y ordenar antes del render.

Campos de busqueda: codigo de lista, version, producto objetivo, actor, estado y kg.

Campos de orden: Codigo, Version, Producto, Fecha, Actor, Kg y Estado. Cada boton alterna ascendente/descendente; el default es Fecha descendente.
