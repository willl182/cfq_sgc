# Technical Finding / Milestone

**Context**: Criterio de estado fisico (P/G) para insumos en formulador-sub_1

## The Discovery

El catalogo base ya traia la columna `TIPO` con valores `P` (polvo) y `G` (granular), pero la aplicacion la trataba como un campo generico. Se modelo explicitamente como `physicalState: 'P' | 'G' | ''` para usarlo como criterio visual y de exportacion sin romper registros manuales o valores no reconocidos.

## Implementation Notes

- `parsePhysicalState` normaliza a mayuscula y solo acepta `P` o `G`; cualquier otro valor queda como `''`.
- El campo se persistio en Convex como opcional (`v.optional(v.union(v.literal('P'), v.literal('G'), v.literal('')))`) para mantener compatibilidad hacia atras.
- Se desplegaron tanto el frontend (Vercel) como el backend Convex production.
