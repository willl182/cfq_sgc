# Technical Finding / Milestone

**Context**: FORMULADOR_CFQ frontend scaffold

## The Discovery

The Apps Script backend returns JSON envelopes with a `data` field, so the frontend API client must unwrap `resp.data` instead of assuming the response body is the array directly. Without that, `fetchMP()` and `fetchFormulas()` would always fall back to empty collections.

The SPA can now boot from a single `index.html` entrypoint, with routing handled in `app.js` and formula actions redirected to the `Formulador` view before loading data.
