# Technical Finding / Milestone

**Context**: CSV loading and catalog integration in formulador-sub_2

## The Discovery

Three critical issues were blocking CSV loading in the browser:

1. **Delimiter detection**: `CsvParser._parseLine()` only supported comma (`,`), but `mp-pt_mzr.csv` uses semicolon (`;`) as delimiter. Added `_detectDelimiter()` method that counts `;`, `,`, and `\t` in the header line and picks the most frequent.

2. **Column alias mapping**: `parseProductos()` expected columns like `ID_PROD`, `PROVEEDOR`, `NOMBRE`, `EXTRAS` which don't exist in `mp-pt_mzr.csv`. The actual CSV has `COD`, `PRODUCTO`, `Test` but no `ID_PROD`. Fixed by making `ID_PROD` fall back to `COD`, and `NOMBRE` fall back to `PRODUCTO`.

3. **Preload path**: `_preloadFromBundledCsv()` was looking for `FORMULADOR - PROD.csv` which doesn't exist. Now prioritizes `insumos_ref/mp-pt_mzr.csv` with `import.meta.url` and relative path fallbacks.

4. **FormulasGuardadas catalog integration**: Added `_loadCatalogo()` and `_resolveNombreDestino()` so the Recetas view can resolve product names from the catalog even when `NOMBRE_DESTINO` is empty.

## Key Files Affected

- `modules/csv-parser.js`: Added `_detectDelimiter()`, updated `_parseLine()` to accept delimiter, fixed `parseProductos()` column mapping
- `modules/catalogo.js`: Updated `_preloadFromBundledCsv()` paths
- `modules/formulas-guardadas.js`: Added `_catalogo`, `_loadCatalogo()`, `_resolveNombreDestino()`
