# Technical Finding / Milestone

**Context**: Reemplazo del filtro nativo por combobox propio.

## The Discovery

El `datalist` nativo permitia escribir para filtrar, pero el navegador renderizaba el menu con un popup oscuro, grande y fuera de la estetica de la app. Se reemplazo por un componente React propio `CatalogCombobox`.

El nuevo componente mantiene comportamiento de desplegable, filtra mientras se escribe y muestra opciones en un menu blanco compacto con scroll. La seleccion continua guardando el `internalId`, por lo que no cambia el modelo de datos ni los calculos.
