# Technical Finding: Auditoria FT/HS Materias Primas vs list_mp.csv

**Context**: Dossier Base Técnica - Cobertura documental de MPs activas

## The Discovery

Se realizó cruce entre las ~60 MPs únicas (por nombre químico) del `list_mp.csv` y los 37 dossiers canónicos en `08_Base_Datos_Tecnica/01_Dossier_Materias_Primas/`. La brecha es significativa:

- **14 MPs** tienen FT + HS completas → dossier canónico existente
- **8 MPs** tienen FT pero les falta HS → dossier existe pero incompleto
- **~38 MPs** no tienen ningún dossier → brecha crítica para cumplimiento ICA

### Metodología usada
1. Glob de `08_Base_Datos_Tecnica/01_Dossier_Materias_Primas/**` para inventariar dossiers
2. Lectura de `list_mp.csv` para extraer MPs únicas por nombre (ignorando proveedor)
3. Cruce manual por nombre químico entre ambas fuentes

### Hallazgo adicional
- Existe ruta anómala `SGC_CALFERQUIM/ kieserite.pdf/01_Ficha_Tecnica/` con 3 archivos FT (KIESERITA G, SULFATO MAGNESIO, SULFATO MAGNESIO Anhidro). Posible artefacto de una carga anterior.
- El reporte `00_Inbox/Estado_Cobertura_FT_HS_20260218.csv` cubre **productos terminados** (05_Dossier_Productos), NO materias primas — confusión potencial entre sesiones.

## Key Files Affected

- `list_mp.csv` — fuente de MPs activas
- `SGC_CALFERQUIM/08_Base_Datos_Tecnica/01_Dossier_Materias_Primas/` — 37 dossiers MP-001 a MP-037
- `SGC_CALFERQUIM/00_Inbox/Estado_Cobertura_FT_HS_20260218.csv` — reporte de productos terminados (no MPs)
- `logs/CURRENT_SESSION.md` — tabla de resultados detallada
