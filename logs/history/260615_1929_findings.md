# Technical Finding / Milestone

**Context**: Ordenamiento del catalogo Convex por nuevo codigo interno.

## The Discovery

La query `catalog:list` usaba `ctx.db.query('catalogItems').collect()`, lo que devuelve documentos en orden fisico/no garantizado para la UI. Se cambio a `withIndex('by_internalId').order('asc')` para que la base se consuma ordenada por el nuevo codigo (`internalId`).

Este cambio no reescribe ni mueve registros en Convex; organiza la salida de la base para la aplicacion y cualquier consumidor de `catalog:list`.
