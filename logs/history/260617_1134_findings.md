# Formato Robusto del Grado N-P-K en Status-Strip

**Contexto**: Formateo de Datos de Nutrientes / Visualización del Grado

## El Descubrimiento

El usuario reportó que al no haber componentes agregados o cuando algún nutriente (como Potasio) es `0.00`, la etiqueta de "Grado" en el status-strip principal de resultados mostraba guiones colgantes vacíos (por ejemplo, `Grado --` o `Grado 26.83-7.93-`).

- **Causa**: El helper `formatGrade` llamaba directamente a `formatPct(value)` para cada nutriente. La función `formatPct` devuelve una cadena vacía `''` si el valor es `0` o menor a `0.001` (para evitar llenar de ceros las tablas de micronutrientes). Esto provocaba que en el grado concatenado `${N}-${P}-${K}` se inyectaran cadenas vacías, resultando en guiones sueltos o vacíos.
- **Solución implementada**:
  Se actualizó `formatGrade` en [main.tsx](file:///home/w182/w421/cfq_sgc/SGC_CALFERQUIM/formulador-sub_1/web/src/main.tsx) para evaluar si el resultado de `formatPct` de un nutriente es falso (cadena vacía) y, de ser así, inyectar por defecto un caracter `"0"`:
  ```typescript
  function formatGrade(composition: CatalogItem['composition']) {
    const n = formatPct(composition.N) || '0'
    const p = formatPct(composition.P) || '0'
    const k = formatPct(composition.K) || '0'
    return `${n}-${p}-${k}`
  }
  ```
- **Resultado**: La etiqueta del grado de formulación y del objetivo ahora es robusta y clara en todo momento. Si la composición está vacía, se visualiza limpiamente como `Grado 0-0-0`. Si el grado formulado carece de potasio pero tiene nitrógeno y fósforo, se visualiza como `Grado 26.83-7.93-0`.
