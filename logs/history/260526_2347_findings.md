# Technical Finding / Milestone

**Context**: Backend import contract validation

## The Discovery

The UI import flow correctly sends the entire `FORMULADOR - PROD.csv` payload to the backend endpoint as `POST ...?action=saveMP`. Playwright interception confirmed that the request body contains the full `data` array with 464 products and that the success path updates the catalog view and local cache.

This validates the initial-load contract between the frontend and the Apps Script backend. The same flow will work against a deployed Google Apps Script URL once configured in the UI.
