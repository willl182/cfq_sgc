# Technical Finding / Milestone

**Context**: UI de estado fisico P/G y edicion habilitada

## The Discovery

El badge de estado fisico se mostraba debajo del badge de clase en el dropdown porque el grid de `combo-option` tenia una columna central fija de 44px, insuficiente para ambos badges. Ademas, el usuario solicito poder editar el criterio P/G directamente desde la interfaz.

## The Solution

1. Se creo el componente `ItemClassBadge` que agrupa clase y estado fisico en un flex container.
2. Se cambio la columna central del dropdown a `auto` para que se ajuste al contenido.
3. Se agrego la mutacion `catalog:updatePhysicalState` y un selector en el drawer de detalle del catalogo.
4. Se agrego selector de estado fisico en los formularios de creacion manual de MP/PT/MZR y de producto objetivo.
