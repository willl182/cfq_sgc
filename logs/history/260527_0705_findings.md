# Hallazgo - Formulador permite PT como insumo

- Se detectó que el filtrado de insumos del formulador estaba limitado a `CLASE === 'MP'`.
- Se amplió el buscador de slots para aceptar `MP` y `PT`.
- Se ajustaron textos y validaciones para usar el término "insumo" en la vista principal.
- El producto destino sigue siendo `PT`; el cambio afecta solo los elementos que pueden entrar en la mezcla.
