# Technical Finding / Milestone

**Context**: App web `formulador-sub_1`, catalogo de listas.

## The Discovery

La clonacion de listas puede implementarse sin crear una nueva mutacion Convex: `saveWithSnapshot` ya soporta crear una lista nueva cuando no recibe `productListId`. Esto permite clonar desde un snapshot o desde la lista viva asociada, asignar un codigo nuevo con `createDisplayCode`, guardar `v1` y abrir la copia en el formulador.
