# Technical Finding / Milestone

**Context**: Backend real del `formulador-sub`

## The Discovery

El backend operativo actual no está en Vercel sino en Google Apps Script + Google Sheets. Vercel únicamente hospeda el frontend estático. La integración directa desde navegador a `script.google.com` introduce CORS y obliga a usar fallback local o un backend intermedio.

- `SGC_CALFERQUIM/formulador-sub/modules/api.js`
- `SGC_CALFERQUIM/formulador-sub/google-apps-script.js`
- `SGC_CALFERQUIM/formulador-sub/Codigo.gs`
- `SGC_CALFERQUIM/formulador-sub/modules/catalogo.js`
- `SGC_CALFERQUIM/formulador-sub/modules/formulas-guardadas.js`
