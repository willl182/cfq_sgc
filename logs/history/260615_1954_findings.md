# Technical Finding / Milestone

**Context**: formulador-sub_1 / vista de snapshots guardados

## The Discovery

Los snapshots ya almacenan `frozenTarget`, por lo que la vista puede mostrar el nombre historico del producto objetivo sin alterar la persistencia ni depender del catalogo vigente. Para datos antiguos o incompletos, la UI puede usar `targetProductId` contra `activeCatalog` y finalmente `SIN_OBJETIVO`.
