# Technical Finding / Milestone

**Context**: Formulador web - cambio de nomenclatura de historico a catalogo de listas

## The Discovery

La pantalla `history` puede presentarse al usuario como un catalogo de listas sin cambiar el almacenamiento interno de snapshots. Los snapshots siguen siendo el registro versionado, pero la UI solo muestra la ultima version por lista mediante `latestSnapshotsOnly`, por lo que conceptualmente funciona como catalogo visible de listas.

## Implementacion

- Se reemplazaron textos visibles de `Historico`/`Snapshots congelados` por `Listas`/`Catalogo de listas`.
- Se reemplazaron textos visibles de `lista viva/listas vivas/catalogo vivo` por `lista`, `listas guardadas` o `catalogo de listas`.
- Se actualizaron nombres de archivos exportados para usar `cfq-listas-guardadas-*` y `cfq-catalogo-listas-*`.
- Se mantuvieron nombres internos `snapshot` para minimizar riesgo tecnico y evitar un refactor de dominio.
