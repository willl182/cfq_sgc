# Technical Finding / Milestone: Desarrollo del Script de Renombrado Masivo de Materias Primas

**Context**: Cierre Documental y Organización del SGC / Automatización del Renombrado de Hojas de Seguridad (HS) al formato `HDS_MP_nombre`.

## The Discovery

Se ha diseñado y desarrollado el script `scratch/renombrar_hds_mp.py` para automatizar de forma segura y precisa el renombrado de todas las Hojas de Seguridad de materias primas (MP) en la carpeta de pruebas `hds_test/`. 

El script destaca por:
1. **Protección de Productos Terminados**: Lee dinámicamente los nombres de archivos de PT para garantizar que permanezcan inalterados.
2. **Normalización Avanzada de Nombres**: Traduce nombres de archivos legacy con numeraciones o caracteres especiales (ej. `01) Citrato de Zinc- Trihidratado-TZC HDS SUCRO 2014.pdf` o `29. Ficha de datos de seguridad de Kieserita...`) a nombres limpios y normalizados (ej. `HDS_MP_CITRATO_DE_ZINC.pdf` o `HDS_MP_KIESERITA.pdf`).
3. **Control y Saneamiento de Duplicados**: Resuelve colisiones eliminando archivos duplicados redundantes de forma segura durante el renombrado.

## Key Files Affected

- `scratch/renombrar_hds_mp.py` (Script de automatización)
- `hds_test/` (Carpeta destino que recibirá la estandarización de nombres)
