# Technical Finding / Milestone

**Context**: CSV import and static frontend validation

## The Discovery

The real `FORMULADOR - PROD.csv` parses cleanly with the existing CSV parser and yields 464 records: 120 classified as `MP` and 344 as `PT`.

The dataset contains a lowercase `g` in `TIPO`, so strict filter logic should normalize case when matching product types.

The frontend shell is reachable as static files through a local HTTP server, which is the correct way to load the ES module app instead of opening `index.html` directly from the filesystem.
